# KMR V Genos 2 — Windows

Nom définitif demandé par Marco : **KMR V Genos 2**.

Décompresser le paquet dans un dossier local, puis lancer **KMR V Genos 2.exe**.
Conserver les DLL et le dossier `resources` à côté de l'exécutable. Fermer
normalement toute ancienne version avant le lancement : une seule instance
doit utiliser le profil à la fois.

La vue instrument conserve le modèle Blender fourni et le rendu interne UHD.
Les captures `genos2-4k.png`, `genos2-4k-top.png` et `genos2-4k-hidpi.png`
mesurent 3840 × 2160. Vue arrangeur ouvre l'interface d'édition et Style Creator
ouvre l'atelier de styles. Voir `GENOS2_INTERFACE.md` pour les commandes et limites.

Le profil existant `%APPDATA%/Genos2Personnel` est conservé afin de retrouver
les réglages, registrations et choix audio. Les formats `.cstyle` et `.csong`
restent compatibles. Les anciens fichiers et paquets ne sont pas déplacés.
Les futures créations IA utilisent le dossier `KMR V Genos 2 AI Styles` ;
le dossier de créations antérieures reste intact.

Les petites sérigraphies restent limitées par les textures source 2000².
Le calcul complet UHD peut être lent ; une image 4K ne garantit pas une cadence
musicale fluide. Audio, MIDI matériel et export Yamaha doivent être validés
séparément. L'application ne contient pas les sons propriétaires du Genos2.
